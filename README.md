# Custom Odoo Modules

مجموعة من موديلات Odoo المخصصة التي طورتها.

A collection of custom Odoo modules.

---

## 📦 الموديلات | Modules

### 1. [testModule](testModule/)
يضيف حقولًا مخصصة إلى `product.template`:
- وزن الوجبة
- السعرات الحرارية
- تاريخ انتهاء الصلاحية
- فلتر "Large Meal"

### 2. [my_meal](my_meal/)
إدارة وجبات العملاء (فطور، غداء، عشاء):
- ربط الوجبات بالعملاء
- حساب تلقائي للأسعار
- عرض القيم الغذائية
- قوائم وفلاتر مخصصة
