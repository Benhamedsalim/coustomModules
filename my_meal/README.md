# My Meal - إدارة وجبات العملاء 🍽️

موديل Odoo متكامل لإدارة وجبات العملاء (فطور، غداء، عشاء) مع حساب تلقائي للأسعار والقيم الغذائية.

An Odoo module to manage customer meals (breakfast, lunch, dinner) with automatic price and nutrition calculations.

## ✨ المميزات | Features

- 🍳 **ثلاث فئات للوجبات**: فطور، غداء، عشاء
- 👤 **ربط الوجبات بالعملاء** (`res.partner`)
- 📝 **تفاصيل كاملة لكل وجبة**:
  - وقت الوجبة
  - ملاحظات
  - قائمة العناصر (منتجات)
- 🧮 **حساب تلقائي للأسعار**:
  - سعر كل عنصر = الكمية × سعر المنتج
  - إجمالي الوجبة = مجموع أسعار العناصر
- 🔥 **عرض القيم الغذائية** (من موديل `testModule`):
  - السعرات الحرارية
  - الوزن
- 📊 **واجهات متعددة**:
  - Form View - نموذج كامل
  - Tree View - قائمة الوجبات
  - Kanban View - عرض مرئي
  - Search View - فلاتر مخصصة
- 🔍 **فلاتر جاهزة** لكل فئة وجبة
- 📋 **قوائم منفصلة** في شريط التنقل
- 🇸🇦 **واجهة عربية كاملة**
